\# Signature-Based Malware Detection



Proyek ini adalah alat deteksi malware sederhana yang bekerja berdasarkan pencocokan signature (tanda tangan) file.



\## Fitur

\- Scan file individual

\- Scan direktori

\- Database signature yang dapat diperbarui
